# 抖音同城获客与0粉起号：开始使用

这份Skill帮助本地门店和上门服务商家，把真实业务变成账号主页、选题、可直接拍摄的口播稿、排期和咨询接待方案。默认从自然流量和手机拍摄开始，按商家的拍摄、接待能力安排工作。

## 最简单的用法

在能读取Skill的AI工具里，把下面这句话中的业务信息换成自己的：

> 使用 douyin-local-acquisition，为我做一套完整的抖音同城获客0粉起号方案。我在苏州吴中做家庭宽带安装和网络检查，主要服务租房和家庭用户，能拍手部操作并配音，每周可拍4条。先从已有信息开始，需要补充的关键信息一次问清。

如果用豆包等需要手动提供资料的工具，上传同目录中的《抖音同城获客起号-Skill完整文档.md》，再输入上面的话。若工具不支持文件，粘贴完整文档，再提供自己的业务信息。提供文档不等于安装，具体导入方法以所用工具实际能力为准。

## 四种直接可复制的指令

### 1. 从0做完整方案

> 使用同城获客起号Skill。我在【城市/区】做【行业】，主推【服务】，希望吸引【客户/需求场景】；每周能拍【次数】，可以【真人出镜/只拍手和现场】。请给我账号搭建、三条置顶完整稿、40条选题、首周逐条完整拍摄包、30天排期、咨询接待话术和复盘表。不要编造价格、年限、授权和客户案例。

方括号是你填写业务信息的地方；不是成品口播稿中的占位符。

### 2. 今天就拍一条

> 继续使用已确认的商家信息，今天拍“【具体问题】”。给我一条30—60秒完整口播稿、两个开头、封面字、手机镜头表、发布文案和一个自然的咨询引导。素材只有【现有素材】，不要重做整套起号方案。

### 3. 首周发完以后复盘

> 按同城获客起号Skill复盘我下面的实际数据。先核对观察窗口和咨询去重口径，区分已知事实、候选原因和待核实项，只给下一周最值得做的一个主要实验。数据如下：【粘贴视频台账和匿名咨询摘要】。

### 4. 给多家门店分别用

> 按同城获客起号Skill，为下面【数量】家门店分别制作定位和首周内容。共用品牌事实，但根据每家门店的区域、客户、服务和真实素材设计，不要只换人名和城市名。门店资料如下：【资料】。

## 第一次会拿到什么

- 一套基于真实业务的主页和获客路径。
- 三条置顶完整拍摄包、四类各10条的选题库。
- 按可用频率制作的首周完整稿及30天执行安排。
- 评论/私信话术、预约步骤、空白内容与线索台账。
- 第7/14/30天复盘规则与下一轮实验。

首周以后的选题按需展开成完整稿。如果想一次取得30条完整稿，请在指令中明确说“30条都要完整口播及镜头表”。不会用标题或提纲充当完整台词。

## 文件说明

- `douyin-local-acquisition/`：标准Skill目录，入口为`SKILL.md`，内含内容生产、执行复盘、官方资料参考和两份空白CSV台账。
- `抖音同城获客起号-Skill完整文档.md`：把核心规则和全部参考内容合并为一个可阅读、可上传的文档。
- `douyin-local-acquisition.skill`：标准Skill目录的ZIP压缩包，供支持此格式的工具导入；不同工具是否支持直接导入需要确认。

Skill负责制作方案与内容。账号里实际开通哪些入口、内容是否已发出、是否产生咨询和成交，需要分别核实；首月目标根据真实数据调整，不承诺固定流量或订单数。
